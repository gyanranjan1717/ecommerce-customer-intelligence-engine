# Data Directory

The processed master customer dataset `scored_customers.csv` (16.8 MB) is generated directly by the Kaggle pipeline:
- **Kaggle Run & Download:** [Brazilian E-Commerce Pipeline](https://www.kaggle.com/code/gyanvats/brazilian-e-commerce)

It contains 96,096 customer records with RFM clusters, XGBoost predicted churn probabilities, and friction features for Power BI dashboarding.
